# 学习工作台

[EN](./README.md) | [中文](./README.zh-CN.md)

一款适用于 macOS 和 Windows 的桌面学习计划应用，可将学习目标和材料整理为每日任务、讲解、测验和学习报告。两个平台共用同一代码库。学习与测评方法参考 ExamPass Skill。

## 下载与安装

下载适用于你的系统的最新安装包：

- **macOS — Apple 芯片（1.0.3）：**[下载 ZIP](https://github.com/wsqUsaqi537/study-workbench/releases/download/v1.0.3/study-workbench-1.0.3-mac-arm64.zip)。解压后将“学习工作台”移入“应用程序”。
- **Windows — x64（1.0.3）：**[下载 EXE](https://github.com/wsqUsaqi537/study-workbench/releases/download/v1.0.3/study-workbench-1.0.3-windows-x64-installer.exe)。运行安装器并选择安装位置。更新时直接运行新安装器，计划和设置会保留；可从 Windows“设置 → 应用”卸载，或运行安装目录内的 `uninstaller.exe`。

安装包未经代码签名，macOS 版本未经公证；Windows 版本尚未在 Windows 电脑上实机测试。

## 使用

使用学习功能前，请在 **API 设置**中配置自己的模型 API。

1. 新建计划，填写主题、目标、学习周期和每日可用时间，并选择备考、平衡或深度学习。周期按日历跨度计算，学习频率可设为每天、隔天或每周指定日期。
2. 可选取或拖入 PDF、DOCX、PPTX、MD、TEX 材料，也可以不添加材料创建计划。目标不明确时，可先讨论目标；备考计划可选填考纲文本或单独添加考纲材料，自学无需考纲。关闭创建窗口后，草稿会保留到本次应用会话结束。
3. 按每日任务学习并记录进度；需要帮助时可查看简要或详细讲解。可在计划页调整学习频率，预览并确认新的未来安排；已完成任务和过去的安排会保留。
4. 每日完成五题测验并查看报告。需要更多准备时，可增加学习时间，或预览并批准调整后的计划。
5. 学习周期结束时完成十题测验并查看总结报告。测验以选择题和填空题为主，期末测验最多包含两道简答题；也可针对错题继续提问。
6. 在头像菜单中设置昵称、头像和语言，可选简体中文或英文。首次启动时应用会跟随系统语言；新生成内容使用所选语言，已有内容保留原语言。

计划和设置保存在本机。可导出计划备份，再从计划页使用 **恢复备份**恢复或迁移到另一台电脑；恢复重复计划时，已有计划会保留。生成内容时，相关信息会发送至所配置的模型服务；发送材料文本前会征求同意。已保存的讲解和测验可再次打开，无需重新请求模型。

仅支持 PDF、DOCX、PPTX、MD、TEX；旧版 DOC/PPT 请先转换，MD/TEX 需为 UTF-8，TEX 按源码读取且不会编译。PDF 提取文本不可读的页面可使用内置中英文 OCR，公式需对照原文核验；PPTX 图片中的文字不会被识别。每份材料最多 30 MB。大型材料会分段读取，可能需要一些时间。
